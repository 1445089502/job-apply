## 快速开始阅读顺序
1. 先看 `01-总体架构.md` 建立全局
2. 再按需深入：`02`（最难点）→ `03` → `04`
3. 落地时看 `05`（建表）→ `08`（部署）
4. 实施前先看 `10`（架构检查报告），确认风险边界与整改优先级
5. 开发排期与提交验收看 `11`（项目实施与交付说明）
6. 本机开发环境和资源限制看 `12`（本机配置评估与实施方案）
