# 07 · 可观测性与安全合规

## 7.1 可观测性

### 指标（Prometheus）
| 指标 | 含义 |
|---|---|
| `apply_success_rate` | 投递成功率 |
| `task_queue_length` | 队列堆积 |
| `llm_latency` | LLM 调用延迟 |
| `collect_success_rate` | 采集成功率 |
| `collect_latency` | 采集耗时 |
| `platform_error_rate` | 每平台错误率 |
| `captcha_count` | 验证码触发次数（封号风险信号）|

### 日志
- 结构化 JSON，含**链路 ID**（贯穿 API→队列→worker）
- 关键动作：采集、投递、状态变更、降级、异常

### 告警
- 投递失败率 > 阈值
- 队列堆积 > 阈值
- 采集连续失败 N 次
- 验证码/风控信号激增

### 追踪
- 请求链路 ID 贯穿全流程，快速定位问题

## 7.2 安全

### 凭证与密钥
- 平台 Cookie：**加密存储**（Fernet/AES），不落明文
- API key / 密码：环境变量 / Vault，**禁止入库**
- 签名密钥集中管理

### 鉴权
- JWT + 角色
- API 全链路鉴权

### 数据安全
- 简历/个人数据：加密存储
- 敏感字段：脱敏展示
- 平台登录态：Redis 托管，失效自动续/人工重登

## 7.3 合规（PIPL + 平台条款）
- **数据最小化**：只采集投递所需字段
- **保留期**：设数据保留期限，到期清理
- **可删除**：用户可一键删除个人数据/简历
- **半自动投递**：投递前人工确认，降低法律与封号风险
- **仅个人使用**：不公开、不商用、不转售
- **频率克制**：遵守平台合理使用规则

## 7.4 Prompt 注入防护
- 恶意 JD 可能携带 prompt 注入 → **JD 清洗**
- LLM 输出结构校验（JSON schema）
- 系统提示词与外部输入隔离
